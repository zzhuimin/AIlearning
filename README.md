# IP 分批使用指引

## 准备 Excel 清单

1. 将待分批的清单保存为 `.xlsx` 文件。
2. 将第 1 行用作表头。
3. 从第 2 行开始，在 A 列填写 IP，在 B 列填写归属服务。
4. 如果某个 IP 未找到归属服务，将该行的 B 列留空。脚本会把该 IP 分到最后一批。

脚本默认读取第一张工作表。输出 CSV 保留数据列和数据行的原有顺序，并在末尾增加「批次」列。

## 运行脚本

在 PowerShell 中进入脚本和清单所在的目录。首次使用时，用 Python 3 安装依赖。

```powershell
python -m pip install openpyxl networkx
```

把下面命令中的 `清单.xlsx` 换成你的 Excel 文件名。每次运行使用新的 CSV 文件名。

```powershell
# 默认分 3 批，目标比例为 10%、30%、60%
python .\allocate-ip-batches.py "清单.xlsx" "分批结果_3批.csv"

# 分 10 批，每批目标比例为 10%
python .\allocate-ip-batches.py "清单.xlsx" "分批结果_10批.csv" --batches 10

# 自定义 10 批的比例
python .\allocate-ip-batches.py "清单.xlsx" "分批结果_自定义.csv" --ratios "5,5,5,5,10,10,10,10,15,25"

# 指定工作表，并按目标比例 10%、30%、60% 分批
python .\allocate-ip-batches.py "清单.xlsx" "分批结果_IP清单.csv" --sheet "IP清单"
```

| 参数 | 用法 |
| --- | --- |
| `--batches 10` | 指定批次数，各批的目标比例相同。批次数须为正整数。 |
| `--ratios "12.5,37.5,50"` | 指定每批比例。填几项就分几批。每项须为非负数，支持小数，合计须为 100%。 |
| `--sheet "IP清单"` | 指定工作表。这个参数可与任一种分批参数一起使用。 |

`--batches` 和 `--ratios` 每次选用一个。省略两者时，脚本使用默认比例 `10,30,60`。

## 分配规则

- **全表比例**。脚本以有归属并参与分配的唯一 IP 数计算配额。前面各批次向下取整，取整余下的 IP 归入最后一批。空白归属的 IP 也归入最后一批。最终占比以全表唯一 IP 总数为分母。
- **服务内比例**。能按目标比例分成整数的服务，优先按精确比例分配。其余服务中，有至少 2 个 IP 的服务优先争取第一批名额。脚本在全表配额内使各服务的分配尽量接近目标比例。
- **重复 IP**。同一 IP 只占一个名额，各行使用同一批次。任一行的归属服务为空时，该 IP 的各行都归入最后一批。同一 IP 有两个不同的非空归属服务时，脚本报告冲突行。

因此，最后一批的实际占比可以高于目标比例。前面某批的配额不足 1 个 IP 时，该批为空。

## 查看结果

1. 在 Excel 中打开结果 CSV。
2. 按「批次」列筛选所需批次。
3. 用 PowerShell 输出的数量和占比核对各批。汇总按唯一 IP 计数，CSV 仍保留重复行。

## 处理常见报错

| 提示 | 处理方法 |
| --- | --- |
| `第 N 行缺少 IP` | 在第 N 行的 A 列补填 IP。 |
| `不是有效的 IP 地址` | 修正提示行的 A 列，填写有效的 IPv4 或 IPv6 地址。 |
| `同时属于` | 核实该 IP 的实际归属。修正提示中冲突的行。 |
| `找不到工作表` | 将 `--sheet` 的值改为 Excel 中的实际工作表名称。 |
| `输出文件已存在` | 更换输出 CSV 文件名。 |
| `ModuleNotFoundError` | 用运行脚本的同一个 `python` 执行依赖安装命令。 |
